# ทดสอบ schema บนเครื่องตัวเอง (ไม่ต้องแตะฐานข้อมูลจริง)

ใช้ตรวจว่ากติกาความปลอดภัยและกติกาข้อมูลยังทำงานถูกต้อง หลังแก้ `schema.sql`
ต้องมี PostgreSQL 15 ขึ้นไปในเครื่อง

```bash
# 1) เตรียมฐานข้อมูลเปล่า
createdb ledger_test

# 2) จำลองสภาพแวดล้อมของ Supabase (schema auth, auth.uid(), role authenticated)
psql -d ledger_test -f supabase/tests/00_supabase_stub.sql

# 3) ติดตั้ง schema จริง
psql -d ledger_test -f supabase/schema.sql

# 4) รันชุดทดสอบ
psql -d ledger_test -f supabase/tests/01_rls_and_rules.sql
```

สิ่งที่ตรวจ 10 ข้อ: สร้างบ้านพร้อมข้อมูลตั้งต้น · รหัสเชิญใช้ได้ครั้งเดียว ·
สมาชิกเห็นข้อมูลชุดเดียวกัน · ยอดคงเหลือคำนวณถูก · สรุปรายเดือนถูก ·
**คนนอกบ้านอ่านไม่ได้และเขียนไม่ได้** · โอนเงินต้องต่างกระเป๋า · รายรับ-รายจ่ายต้องมีหมวดหมู่ ·
จำนวนเงินต้องมากกว่า 0 · trigger `updated_at` ทำงาน

ทุกบรรทัดที่ขึ้นต้นด้วย `NOTICE: ผ่าน —` คือการทดสอบที่คาดว่าจะต้องล้มเหลวแล้วล้มเหลวจริงตามคาด
