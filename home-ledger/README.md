# บัญชีบ้านเรา (Home Ledger)

โปรแกรมบัญชีรับ-จ่ายสำหรับใช้ในบ้าน 4 คน เปิดใช้ได้จากมือถือ แท็บเล็ต หรือคอมพิวเตอร์
ข้อมูลเก็บบนคลาวด์ ทุกคนเห็นข้อมูลชุดเดียวกันแบบเรียลไทม์ และยังบันทึกได้แม้เน็ตหลุด

```
home-ledger/
├── docs/
│   ├── DESIGN.md      ← เอกสารออกแบบระบบ (อ่านก่อนถ้าอยากเข้าใจภาพรวม)
│   └── SETUP.md       ← ขั้นตอนติดตั้งจริง ตั้งแต่ศูนย์จนใช้งานได้ทั้งบ้าน
├── supabase/
│   └── schema.sql     ← โครงสร้างฐานข้อมูล + สิทธิ์ + ข้อมูลตั้งต้น (วางใน SQL Editor แล้วกด Run)
├── artifact/
│   └── app.html       ← เวอร์ชันเปิดใช้ได้ทันที (ไฟล์เดียว เก็บข้อมูลบนคลาวด์ของ Claude)
└── web/               ← เวอร์ชัน Supabase (React + Vite, ติดตั้งเป็นแอปบนมือถือได้แบบ PWA)
```

## สิ่งที่ทำได้

| ด้าน | รายละเอียด |
|---|---|
| บันทึก | รายรับ / รายจ่าย / โอนเงินระหว่างกระเป๋า ระบุหมวดหมู่ กระเป๋าเงิน เจ้าของรายการ และบันทึกช่วยจำ |
| ใช้ร่วมกัน | 1 บ้าน = ข้อมูลชุดเดียว เชิญสมาชิกด้วยรหัส 6 หลัก แยกดูได้ว่าใครใช้เท่าไหร่ |
| ภาพรวม | ยอดคงเหลือแต่ละกระเป๋า สรุปรับ-จ่ายรายเดือน โดนัทชาร์ตตามหมวด งบประมาณรายเดือน |
| รายงาน | แนวโน้มย้อนหลัง 3/6/12 เดือน แยกตามหมวด และแยกตามคน |
| ใช้ได้ทุกที่ | เว็บแอปติดตั้งลงหน้าจอโฮมได้ ใช้งานออฟไลน์ได้ ข้อมูลค้างจะส่งขึ้นคลาวด์ให้เองเมื่อเน็ตกลับมา |
| เป็นเจ้าของข้อมูล | ส่งออกเป็น CSV ได้ตลอดเวลา ฐานข้อมูลเป็น PostgreSQL มาตรฐาน ย้ายออกได้ |

## สองทางเลือก

**1. เปิดใช้ได้เลย ไม่ต้องติดตั้งอะไร** — เวอร์ชัน Artifact
https://claude.ai/code/artifact/b9bf9459-f6e4-4909-bbed-a71d1841706c
ซอร์สอยู่ที่ `artifact/app.html` เป็นไฟล์ HTML ไฟล์เดียว เก็บข้อมูลบนคลาวด์ของ Claude
เปิดลิงก์เดียวกันจากเครื่องไหนก็เห็นข้อมูลชุดเดียวกัน อัปเดตให้เองแบบเรียลไทม์
เหมาะสำหรับเริ่มใช้วันนี้ ข้อจำกัดคือคนที่จะเข้ามาใช้ร่วมกันต้องอยู่ในองค์กร Claude เดียวกับเจ้าของลิงก์

**2. เป็นเจ้าของข้อมูลเองเต็มที่** — เวอร์ชัน Supabase ใน `web/`
ตั้งค่าครั้งเดียวประมาณ 30–45 นาที แล้วสมาชิก 4 คนสมัครบัญชีของตัวเองเข้ามาใช้ร่วมกันได้
ข้อมูลอยู่ในฐานข้อมูล PostgreSQL ของคุณเอง ย้ายออกได้ตลอด

## เริ่มใช้เร็ว ๆ (เวอร์ชัน Supabase)

```bash
# 1) สร้างโปรเจกต์ Supabase (ฟรี) แล้วรัน supabase/schema.sql ใน SQL Editor
# 2) ตั้งค่าและรันแอป
cd web
cp .env.example .env      # ใส่ VITE_SUPABASE_URL และ VITE_SUPABASE_ANON_KEY
npm install
npm run dev               # เปิด http://localhost:5173
```

ขั้นตอนเต็มรวมถึงการนำขึ้นออนไลน์ให้ทั้งบ้านใช้ อยู่ใน [docs/SETUP.md](docs/SETUP.md)

## ค่าใช้จ่าย

ใช้ฟรีทั้งหมด — Supabase แพ็กเกจฟรีให้ฐานข้อมูล 500 MB และผู้ใช้ 50,000 คน/เดือน
ส่วนโฮสต์หน้าเว็บใช้ Vercel / Netlify / Cloudflare Pages แบบฟรีได้ ครอบครัว 4 คนบันทึกวันละ 20 รายการ
ใช้พื้นที่ประมาณ 3 MB ต่อปี ยังเหลืออีกมาก
