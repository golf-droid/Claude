# ขั้นตอนติดตั้ง — จากศูนย์จนทั้งบ้านใช้งานได้

ใช้เวลาประมาณ 30–45 นาที ทำครั้งเดียว ไม่ต้องเขียนโค้ดเพิ่ม

---

## ขั้นที่ 1 — สร้างโปรเจกต์ Supabase (ฟรี)

1. เข้า https://supabase.com กด **Start your project** แล้วสมัคร/ล็อกอิน (ใช้บัญชี GitHub หรืออีเมลก็ได้)
2. กด **New project**
   - **Name:** `home-ledger` (หรือชื่ออะไรก็ได้)
   - **Database Password:** ตั้งรหัสผ่านที่แข็งแรง **แล้วเก็บไว้ให้ดี** (ใช้ตอน `pg_dump` สำรองข้อมูล)
   - **Region:** เลือก **Southeast Asia (Singapore)** จะเร็วที่สุดสำหรับผู้ใช้ในไทย
3. รอสร้างเสร็จประมาณ 2 นาที

## ขั้นที่ 2 — สร้างตารางและกติกาความปลอดภัย

1. ในเมนูซ้าย เลือก **SQL Editor** → **New query**
2. เปิดไฟล์ `supabase/schema.sql` ในโปรเจกต์นี้ **คัดลอกทั้งไฟล์** มาวาง
3. กด **Run** (หรือ Ctrl+Enter) — ต้องขึ้น `Success. No rows returned`

> ไฟล์นี้รันซ้ำได้ ถ้าอนาคตมีการอัปเดตโครงสร้าง ก็วางรันใหม่ได้เลยโดยข้อมูลเดิมไม่หาย

**ตรวจว่าเรียบร้อย:** ไปที่ **Table Editor** ควรเห็น 7 ตาราง
(`households`, `household_members`, `household_invites`, `accounts`, `categories`, `transactions`, `budgets`)
และทุกตารางมีป้าย **RLS enabled** สีเขียว

## ขั้นที่ 3 — ตั้งค่าระบบล็อกอิน

ไปที่ **Authentication → Sign In / Providers** (บางเวอร์ชันอยู่ใต้ **Providers**)

- เปิด **Email** ไว้ (เปิดอยู่แล้วโดยค่าเริ่มต้น)
- ปิด **Confirm email** ได้ถ้าอยากให้สมัครแล้วใช้ได้เลยไม่ต้องรออีเมลยืนยัน
  (สำหรับใช้กันเองในบ้าน 4 คน สะดวกกว่า — อยู่ใต้ **Authentication → Sign In / Providers → Email**)
- ถ้าอยากกันคนนอกสมัครเข้ามาให้แน่นหนา: หลังจากทุกคนในบ้านสมัครครบแล้ว
  ให้ปิด **Allow new users to sign up** ที่ **Authentication → Sign In / Providers**

## ขั้นที่ 4 — เอาคีย์มาใส่ แล้วเปิดแอป

มีสองทาง เลือกทางเดียว

### ทาง A — ผ่านเว็บล้วน ๆ ไม่ต้องลงอะไรในเครื่อง (แนะนำ)

ข้ามไปทำขั้นที่ 6 ได้เลย แล้วค่อยกลับมาสมัครสมาชิกที่ขั้นที่ 5
เพราะ Vercel จะ build ให้บนคลาวด์ โดยที่เครื่องคุณไม่ต้องมี Node.js

### ทาง B — รันในเครื่องก่อน (ถ้าอยากลองแก้โค้ดเอง)

1. ที่ Supabase ไปที่ **Project Settings → API** (หรือ **Data API**) จดสองค่านี้ — ใช้ทั้งสองทาง
   - **Project URL** เช่น `https://abcdefghijkl.supabase.co`
     (ถ้าเห็นแต่ Project ID ให้ประกอบเองเป็น `https://<project-id>.supabase.co`)
   - **คีย์สาธารณะ** ใส่ได้ทั้งสองแบบ แล้วแต่ว่าหน้าจอคุณแสดงแบบไหน
     - **Publishable key** ขึ้นต้นด้วย `sb_publishable_...` ← แนะนำ เป็นรูปแบบใหม่ที่ Supabase กำลังเปลี่ยนมาใช้
     - **anon public key** ข้อความยาวขึ้นต้นด้วย `eyJ...` ← แบบเดิม ยังใช้ได้ปกติ

   > คีย์สองแบบข้างบนออกแบบมาให้เปิดเผยได้ ปลอดภัยเพราะมี RLS คุมอยู่
   > แต่ **`service_role` / `sb_secret_...` ห้ามนำมาใส่ในแอปเด็ดขาด** เพราะข้ามทุกกติกาความปลอดภัย

2. ในเครื่อง:

```bash
cd home-ledger/web
cp .env.example .env
```

3. แก้ไฟล์ `.env` ให้เป็นค่าจริง

```
VITE_SUPABASE_URL=https://abcdefghijkl.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
```

4. ติดตั้งและรัน

```bash
npm install
npm run dev
```

เปิด http://localhost:5173 → ต้องเห็นหน้าเข้าสู่ระบบ

## ขั้นที่ 5 — สร้างบ้านและเชิญสมาชิก

1. คนแรก (เช่นพ่อ) กด **สมัครใหม่** ด้วยอีเมล + รหัสผ่าน
2. หน้าถัดไปเลือก **สร้างบ้านใหม่** ใส่ชื่อเล่นของตัวเอง แล้วกดสร้าง
   ระบบจะสร้างกระเป๋าเงิน 3 อัน และหมวดหมู่มาตรฐาน 13 หมวดให้อัตโนมัติ
3. ไปหน้า **ตั้งค่า → สมาชิกในบ้าน → สร้างรหัสเชิญ** จะได้รหัส 6 หลัก
4. คนที่ 2–4 สมัครบัญชีของตัวเอง แล้วเลือก **เข้าร่วมด้วยรหัส** ใส่รหัสที่ได้
   (รหัสหนึ่งอันใช้ได้ครั้งเดียว ต้องสร้างใหม่สำหรับแต่ละคน หมดอายุใน 7 วัน)
5. ปรับ **ยอดยกมา** ของแต่ละกระเป๋าให้ตรงกับเงินที่มีอยู่จริงวันนี้
   (ตั้งค่า → กระเป๋าเงิน → แตะชื่อกระเป๋า) ยอดคงเหลือจะได้ตรงความจริงตั้งแต่วันแรก

## ขั้นที่ 6 — นำขึ้นออนไลน์ให้ใช้ได้ทุกที่

### วิธีที่ง่ายที่สุด: Vercel เชื่อมกับ GitHub (ทำผ่านเว็บทั้งหมด)

1. เข้า https://vercel.com กด **Sign up** เลือก **Continue with GitHub**
2. กด **Add New… → Project** เลือก repo นี้ แล้วกด **Import**
3. ตั้งค่าตอน import ให้ตรงตามนี้
   - **Root Directory:** กด Edit แล้วเลือก `home-ledger/web` ← **สำคัญที่สุด ถ้าไม่ตั้ง จะ build ไม่ผ่าน**
   - **Framework Preset:** Vite (ปกติจะตรวจเจอเอง)
   - Build Command / Output Directory ปล่อยตามค่าเริ่มต้น — ไฟล์ `vercel.json` ในโปรเจกต์ตั้งไว้ให้แล้ว
4. เปิดหัวข้อ **Environment Variables** ใส่สองตัวนี้ (ค่าจากขั้นที่ 4)

   | Name | Value |
   |---|---|
   | `VITE_SUPABASE_URL` | `https://xxxx.supabase.co` |
   | `VITE_SUPABASE_ANON_KEY` | `eyJhbGciOi...` |

5. กด **Deploy** รอประมาณ 1–2 นาที จะได้ลิงก์แบบ `https://ชื่อโปรเจกต์.vercel.app`
6. ถ้าโค้ดอยู่คนละ branch กับ default branch ของ repo: ไปที่
   **Settings → Git → Production Branch** แล้วเปลี่ยนเป็น branch ที่ใช้จริง จากนั้นกด **Redeploy**

หลังจากนี้ทุกครั้งที่โค้ดใน branch นั้นเปลี่ยน Vercel จะ build ใหม่ให้อัตโนมัติ

> **ถ้าตอน Import แล้วเลือก Root Directory ไม่เจอ `home-ledger/web`**
> แปลว่า **default branch ของ repo ยังไม่มีโฟลเดอร์นี้** เพราะ Vercel อ่านจาก default branch เสมอ
> แก้โดยไปที่ GitHub → repo → **Settings → General → Default branch** แล้วสลับเป็น branch ที่มีโค้ดนี้
> (หรือ merge branch นั้นเข้า default branch) จากนั้นค่อยกลับมา Import ใหม่

> **ถ้า deploy แล้วหน้าขาว** เกือบทุกครั้งเกิดจาก Root Directory ไม่ได้ตั้งเป็น `home-ledger/web`
> หรือลืมใส่ environment variables — แก้แล้วต้องกด **Redeploy** ทุกครั้ง เพราะค่าพวกนี้ถูกฝังตอน build

### ทางเลือกอื่น

| บริการ | วิธี | หมายเหตุ |
|---|---|---|
| Netlify | เชื่อม Git → ตั้ง base directory `home-ledger/web` | มี `netlify.toml` ตั้งค่าไว้ให้แล้ว |
| Cloudflare Pages | เชื่อม Git → root `home-ledger/web`, build `npm run build`, output `dist` | เร็วในไทย |
| ผ่านคอมมานด์ไลน์ | `cd home-ledger/web && npx vercel --prod` | ต้องมี Node.js ในเครื่อง |

**เรื่อง client-side routing:** แอปใช้ URL แบบ `/transactions`, `/reports` ซึ่งต้องให้เซิร์ฟเวอร์ส่ง
`index.html` กลับมาทุก path ไฟล์ `vercel.json`, `netlify.toml` และ `public/_redirects` ในโปรเจกต์
ตั้งค่านี้ไว้ให้เรียบร้อยแล้ว ถ้าโฮสต์เองด้วย nginx ให้ใส่

```nginx
location / {
  try_files $uri $uri/ /index.html;
}
```

## ขั้นที่ 7 — ติดตั้งเป็นแอปบนมือถือ

เป็น PWA ติดตั้งลงหน้าจอโฮมได้เหมือนแอปจริง ไม่ต้องผ่าน App Store

- **iPhone/iPad (Safari):** เปิดลิงก์ → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
- **Android (Chrome):** เปิดลิงก์ → เมนู ⋮ → **ติดตั้งแอป** / **เพิ่มไปยังหน้าจอหลัก**
- **คอมพิวเตอร์ (Chrome/Edge):** ไอคอนติดตั้งท้ายแถบที่อยู่

ติดตั้งแล้วจะเปิดเต็มจอ ไม่มีแถบเบราว์เซอร์ และเปิดดูข้อมูลเดิมได้แม้ไม่มีเน็ต

## ปัญหาที่พบบ่อย

**ขึ้น "ยังตั้งค่าคลาวด์ไม่เสร็จ"**
ยังไม่มีไฟล์ `.env` หรือชื่อตัวแปรผิด ต้องขึ้นต้นด้วย `VITE_` เท่านั้น และต้องรัน `npm run dev` ใหม่หลังแก้ไฟล์

**ล็อกอินได้แต่ไม่เห็นข้อมูล / ขึ้นว่าเชื่อมต่อฐานข้อมูลไม่ได้**
มักเกิดจาก `schema.sql` รันไม่ครบ ให้กลับไปรันใหม่ทั้งไฟล์ แล้วดูว่ามี error สีแดงตรงไหนไหม

**สมัครแล้วไม่ได้รับอีเมลยืนยัน**
ปิด **Confirm email** ตามขั้นที่ 3 หรือยืนยันให้ด้วยมือที่ **Authentication → Users** → เลือกผู้ใช้ → Confirm

**ใส่รหัสเชิญแล้วขึ้นว่าถูกใช้ไปแล้ว**
รหัสหนึ่งอันใช้ได้คนเดียว ให้เจ้าบ้านกดสร้างรหัสใหม่

**บันทึกแล้วแต่แถบด้านบนขึ้น "รอส่ง 3"**
เน็ตขาดอยู่ ข้อมูลถูกเก็บในเครื่องแล้วและจะส่งขึ้นเองเมื่อเน็ตกลับมา หรือกด **ซิงก์ข้อมูลเดี๋ยวนี้** ในหน้าตั้งค่า

**อัปเดตแอปแล้วมือถือยังเห็นของเก่า**
Service Worker แคชไว้ ให้ปิดแอปแล้วเปิดใหม่ 1–2 ครั้ง หรือรีเฟรชแบบล้างแคช

**โปรเจกต์ Supabase ถูก pause**
แพ็กเกจฟรีจะพักโปรเจกต์ที่ไม่มีการใช้งาน 7 วัน เข้า dashboard กด **Restore** ข้อมูลไม่หาย

## การสำรองข้อมูล

- **ง่ายที่สุด:** หน้าตั้งค่า → **ส่งออกข้อมูลเป็น CSV** เดือนละครั้ง เก็บใน Google Drive
- **เต็มรูปแบบ:** เอา connection string จาก **Project Settings → Database** แล้วรัน

```bash
pg_dump "postgresql://postgres:[รหัสผ่าน]@db.[project-ref].supabase.co:5432/postgres" > backup.sql
```
